\subsection*{How does each algorithm’s out-of-sample performance compare
with each of the other algorithms?}

Decision tree model demonstrates the highest test set accuracy of 0.868 and hence the best performing model as per the primary assessment metric. This model also provides the lowest Brier score, implying that the predicted probabilities are quite calibrated.

\medskip
Logistic regression and neural network perform equally well by providing the highest ROC AUC scores of 0.904, demonstrating a superior discrimination between high and low earners. However, the overall classification accuracy of these models is slightly inferior to that achieved by decision trees. In particular, the neural network model has a Brier score indicating poor probability calibration.

\medskip
The performance of k-nearest neighbors model lags behind those of other models under the given metrics. In general, there appears to be a trade-off between accuracy and rank discrimination. As accuracy was used for model tuning, the decision tree model can be considered optimal.

\subsection*{Note on SVM}

The Support Vector Machine algorithm was not included in the final comparisons due to computation and convergence problems. While tuning the parameters, several error messages stating "line search fails" kept showing up even after several attempts using various parameter sets, implying unstable computation during the tuning process.

\medskip
Although the training time was lengthy, the algorithm was unable to converge into stable solutions, failing the tuning process. Thus, the SVM algorithm was not considered in the final comparison.
